NOVA AI CHATBOT — HTML, CSS & JAVASCRIPT

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html (or open it with Live Server in VS Code).

FILES
- index.html  : App structure
- style.css   : Responsive styling and dark mode
- script.js   : Chat interactions and demo response rules

NOTE
This is a front-end chatbot demo. It does not call a real AI model or require an API key.
For real AI-generated answers, connect a trusted AI API through a backend server.
Never put a private API key directly in browser JavaScript.
